# Card Pang (card-pang.com)

**Card Pang**은 신용카드 이용 구조와 관련된 정보를  
이해하기 쉽게 정리한 **정보 제공형 웹사이트**입니다.

본 저장소는 card-pang.com에서 사용되는  
정적 HTML 기반 페이지의 **백업 및 버전 관리**를 목적으로 운영됩니다.

---

## 🔍 About This Project

- 서비스명: Card Pang
- 도메인: https://card-pang.com
- 유형: 정보 제공용 정적 웹사이트
- 기술 스택:  
  - HTML5  
  - CSS3  
  - Vanilla JavaScript  

본 프로젝트는 프레임워크에 의존하지 않는  
**경량 정적 구조**를 사용하여 빠른 로딩과 안정적인 배포를 지향합니다.

---

## 📄 Content Policy

Card Pang은 다음 원칙을 따릅니다.

- ❌ 직접적인 결제, 금융 거래를 수행하지 않습니다
- ❌ 사용자 개인정보를 수집하지 않습니다
- ⭕ 일반적인 정보 제공 및 가이드 목적의 콘텐츠만 포함합니다
- ⭕ 검색 사용자에게 도움이 되는 구조와 문맥을 우선합니다

모든 콘텐츠는 **정보 전달 목적**으로 작성됩니다.
